# css-frameworks

#Samigram

Samigram is a simple social media application. You can look through a Login, register, feed and profile page. This is a project used to familiarize myself with bootstrap/sass.

##Technologies
-HTML
-JAVASCRIPT
-SASS
-BOOTSTRAP

#Features

##Login/Register page:
Login/register with email and password
password has to be at least 8 symbols

##Feed page:
View posts made by people
like/comments/post time/caption/image/profile picture/profile name

##Profile page:
Follow information
All posts displayed
profile information such as pfp, bio and name

##Installation

Clone the repository:

```bash
git clone https://github.com/celds/css-frameworks.git
```

Go to the project folder:

```bash
 cd css-frameworks
```

Install dependencies:

```bash
npm install
```

## View the project

open an index.html file and open it with a live server with the live server extension.
